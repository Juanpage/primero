# Primero

Sitio web corporativo estático para la marca Primero, orientada a servicios de consultoría y desarrollo digital.

## Estructura

- `index.html`: Página principal con navegación, secciones de servicios, metodología, testimonios, FAQ y formulario de contacto.
- `styles.css`: Hoja de estilos responsiva con énfasis en accesibilidad, tipografía y componentes reutilizables.
- `scripts.js`: Comportamiento interactivo (menú móvil, desplazamiento suave, acordeón y validación básica del formulario).

## Uso

1. Descarga o clona el repositorio.
2. Abre `index.html` en cualquier navegador moderno.
3. No requiere dependencias ni compilación.

## Accesibilidad y buenas prácticas

- Navegación por teclado optimizada con enlaces de salto y focos visibles.
- Componentes responsivos preparados para pantallas móviles y de escritorio.
- Validaciones de formulario en el cliente y mensajes personalizados.

## Personalización

Actualiza los contenidos de texto en `index.html` y ajusta los colores o tipografías en `styles.css` según la identidad de tu marca.
